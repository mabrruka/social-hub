
# Social Hub

Social Hub is a social media website where users can create accounts, sign in, manage their profiles, and connect with others.

## Features

- User registration and login
- Secure password hashing
- User profiles
- Search page
- Create post page
- Notifications page
- Settings page
- MySQL database

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- Prisma ORM
- MySQL
- Docker
